# 🤖 BobAI

*BobAI is the custom AI chatbot powering my future website.*

## The Backstory
I finally started this project thanks to Hack Club and their **Stardance** event. I've wanted to build something like this for a long time, but something was always holding me back. This event gave me the perfect reason to just go for it.

## How It Works
BobAI is based on **Meta Llama 3.1 8B**. 

To make the chatbot more helpful and bring a better user experience, I fine-tuned it using the **UltraFeedback** dataset. Originally, my dream was to train a model entirely from scratch, but my PC just couldn't handle training something that big. Then I decided to pick a powerful open-source model and fine-tune it to fit my exact needs.
